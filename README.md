# Wanantara Foundation — Landing Page

Situs landing page resmi **Wanantara Foundation**, sebuah organisasi yang bergerak di bidang **mitigasi iklim berbasis tapak**.

🌐 **Live:** [wanantara.org](https://wanantara.org)

## Struktur

| Berkas | Keterangan |
|---|---|
| `index.html` | Halaman utama |
| `program.html` | Halaman program |
| `tentang.html` | Halaman tentang |
| `kontak.html` | Halaman kontak |
| `kebijakan.html` | Halaman kebijakan |
| `support.js` | Skrip pendukung |
| `assets/` | Aset (gambar, dsb.) |
| `CNAME` | Konfigurasi domain kustom |

## Catatan

> 📝 Situs statis yang di-hosting melalui GitHub Pages dengan domain kustom `wanantara.org`.
